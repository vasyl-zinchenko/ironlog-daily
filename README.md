# IRONLOG DAILY — Мобільний PWA-застосунок щоденних силових тренувань

**IRONLOG DAILY** — це ультрасучасний, повністю автономний прогресивний веб-застосунок (PWA) для двох друзів, які тренуються у спортзалі. Застосунок щодня показує **рівно одну готову програму тренування**, не перевантажуючи зайвими полями введення чи налаштуваннями.

Прийшли в зал — відкрили застосунок — бачите тренування на сьогодні з чіткими підходами, повтореннями, схемами руху, картою м'язів, правилами техніки та альтернативами.

---

## ⚡️ Ключові принципи та архітектура

1. **Одне тренування на день:**
   - Жодного хаосу з десятків вкладок, списків чи архівних меню на першому плані.
   - На головному екрані представлена лише актуальна програма: дата, номер у циклі (`01 / 12`), цільові м'язи, орієнтовний час та перелік вправ.

2. **Автоматична зміна програми за календарем:**
   - Алгоритм відстежує локальну дату пристрою (`YYYY-MM-DD`) з урахуванням часових поясів.
   - При настанні нової доби застосунок автоматично показує наступну програму.
   - Якщо тренування пропущені (минуло 2, 3 чи більше днів), зміщення по циклу розраховується автоматично за кількістю пройдених діб.

3. **Безпечне оновлення програми та захист від випадкових натискань:**
   - **Діалогове вікно підтвердження**: при натисканні «Оновити програму» відкривається стильне модальне вікно з попереднім переглядом поточного та наступного тренування.
   - **Повернення до попереднього дня**: якщо програму було оновлено випадково або потрібно повернутися до вчорашнього дня, доступна кнопка **«Попередній день»** (або швидка дія «Повернути» прямо у спливаючому сповіщенні).
   - **Кнопка оновлення у шапці (Хедер)**: швидкий перехід до наступного тренування та повернення назад доступні як вгорі екрана, так і внизу списку вправ.

4. **100% Автономність (Zero-Backend & Offline-First):**
   - Жодної реєстрації, паролів, серверних баз даних, Supabase, Firebase чи зовнішніх API.
   - Повний кеш у Service Worker через `vite-plugin-pwa` та Workbox.
   - Застосунок завантажується миттєво навіть у підвальних спортзалах за повної відсутності мобільного зв'язку чи Wi-Fi.

5. **Візуальний стиль: White & Blue Edition (Світла палітра від білого до блакитного):**
   - Абсолютно світлий, чистий та свіжий інтерфейс без темних розривів чи важких тонів.
   - Гармонійний градієнт від кристально чистого білого (`#FFFFFF`) до ніжно-блакитного льоду (`#F0F7FD` $\to$ `#E0F2FE`).
   - Різноманітні функціональні відтінки блакитного: кобальтовий синій (`#0284C7`) для головних кнопок, небесний блакитний (`#0EA5E9` / `#38BDF8`) для активних м'язів та індикаторів, пастельний лазурний (`#BAE6FD`) для рамок та плашок.
   - Глибокий сланцевий синій (`#0F172A`, `#334155`) для ідеальної контрастності та зручного читання тексту в спортзалі.

## 🏋️‍♂️ Доступне обладнання та програми

Усі 12 програм циклу розроблені суворо під наявне обладнання залу:
- **Штанга та лава для жиму** (горизонтальна, з регулюванням кута).
- **Гантельний ряд**.
- **Гірі** (16 кг та 24 кг).
- **Жим ногами в тренажері** (основний акцент для квадрицепсів).
- **Тренажер для литок**.
- **Тренажер горизонтальної тяги до пояса** (блочний важіль / сидячи).
- **Тренажер для згинання рук на біцепс**.
- **Турнік для підтягувань** (широкий, середній, зворотний хват).
- **Дошка для віджимань із розміткою різних хватів** (push-up board).
- **Власна вага тіла**.

> 💡 **Безпека хребта:** У програмах відсутні класичні станові тяги та присідання з важкою штангою на плечах. Для розвитку ніг використовується безпечний жим ногами з контрольованою амплітудою та румунська тяга з гантелями/гірями.

### Діапазони повторень

Замість монотонних схем $3 \times 5$ чи $3 \times 10$, застосовано науково обґрунтовану варіативність:
- **6–8** — компаундні силові рухи (жим лежачи, важкий жим ногами).
- **8–10 / 8–12** — гіпертрофічні базові вправи (тяги до пояса, віджимання з дефіцитом).
- **10–12 / 10–15** — ізоляція та робота з гірями/гантелями (махи, жими стоячи).
- **12–15 / 12–20 / 15–20** — пампінг, литки, дельти, кора та метаболічний стрес.

## 🔍 Інтерактивна картка кожної вправи

Кожна вправа у списку програми розгортається в один клік і містить:

1. **Локальні векторні схеми руху (SVG):**
   - Початкове та кінцеве положення атлета.
   - Стрілки напрямку вектора сили та траєкторії руху.
   - Жодних сторонніх картинок або повільних зовнішніх завантажень.
2. **Анатомічна карта тіла (Muscle Map):**
   - Подвійний силует людини (спереду та ззаду).
   - Візуальне підсвічування цільових м'язів яскравим лаймом (`#C7F36B`) та синергістів сигнальним полум'ям (`#FF795E`).
3. **Правила техніки та фокус уваги:**
   - 3 чіткі маркери технічного виконання.
   - Ментальний акцент руху (Mind-Muscle connection).
   - Список із 3 найпоширеніших критичних помилок.
4. **Мінімум 2 практичні альтернативи:**
   - Повноцінні вправи-замінники на випадок, якщо тренажер зайнятий або потрібна адаптація під суглоби.
   - Зазначення необхідного обладнання та обґрунтування заміни.

## 🚀 Встановлення та запуск

### Вимоги
- **Node.js** версії 18 або новішої
- **npm** версії 9 або новішої

### 1. Клонування та встановлення залежностей

```bash
git clone <url-репозиторію>
cd fitnes-app
npm install
```

### 2. Запуск локального сервера розробки

```bash
npm run dev
```
Після запуску відкрийте у браузері посилання: `http://localhost:5173`.

### 3. Запуск юніт-тестів

```bash
npm test
```
Тести перевіряють:
- Правильність переходу дат без зміщення через UTC.
- Автоматичний розрахунок зсуву при пропуску днів.
- Ручне оновлення програми та замкнений цикл з 12 до 01.
- Валідність та наявність техніки, схем, альтернатив для всіх 12 програм.

### 4. Перевірка типів TypeScript

```bash
npm run typecheck
```

### 5. Збірка для продакшну

```bash
npm run build
```
Згенеровані файли розміщуються в каталозі `dist/`, включаючи оптимізований Service Worker (`sw.js`).

### 6. Попередній перегляд продакшн-збірки

```bash
npm run preview
```

## 📱 Встановлення як додатка (PWA) на телефон

Застосунок оптимізовано під мобільні пристрої та підтримує встановлення на екран "Додому" без використання App Store чи Google Play.

### На Android (Google Chrome, Brave, Samsung Internet):
1. Відкрийте посилання на застосунок у браузері Chrome.
2. Внизу екрана автоматично з'явиться банер **«Встановити застосунок на головний екран»** (або натисніть меню із трьома крапками у правому верхньому кутку).
3. Виберіть пункт **«Встановити застосунок»** або **«Додати на головний екран»**.
4. Застосунок з'явиться серед ваших програм та запускатиметься у повноекранному режимі без браузерного інтерфейсу.

### На iPhone / iOS (Safari):
1. Відкрийте посилання на застосунок у браузері **Safari**.
2. Натисніть кнопку **«Поділитися»** (іконка квадрата зі стрілкою вгору по центру нижньої панелі).
3. Прокрутіть список униз і виберіть пункт **«На початковий екран»** (*Add to Home Screen*).
4. Натисніть **«Додати»** у правому верхньому кутку.
5. Застосунок відкривається як нативний додаток з підтримкою жестів змахування та адаптацією під Dynamic Island / виріз екрана.

## 📴 Перевірка роботи в офлайн-режимі

1. Відкрийте застосунок у браузері або запустіть встановлений PWA на смартфоні.
2. Дочекайтеся першого завантаження (індикатор у шапці покаже статус **«В мережі»**).
3. Увімкніть **«Режим польоту»** (Airplane Mode) на пристрої або в DevTools Chrome перейдіть у вкладку `Network` і оберіть пресет `Offline`.
4. Статус у шапці зміниться на **«Офлайн-режим»**.
5. Оновіть сторінку: застосунок миттєво завантажиться з локального кешу Service Worker.
6. Перевірте роботу кнопки **«ОНОВИТИ ПРОГРАМУ»**, розгортання вправ, відображення векторних ілюстрацій та анатомічної карти — усе функціонує на 100% без підключення до Інтернету.

## 🌐 Розгортання (Deployment)

Оскільки проєкт повністю клієнтський і не потребує серверної частини чи баз даних, його можна безкоштовно опублікувати на будь-якому статичному хостингу:

### Варіант 1: Cloudflare Pages
1. Підключіть репозиторій у кабінеті Cloudflare Pages.
2. Build command: `npm run build`
3. Build output directory: `dist`
4. Натисніть Deploy.

### Варіант 2: Netlify
1. Перетягніть папку `dist` у вікно Netlify Drop або підключіть Git-репозиторій.
2. Build command: `npm run build`
3. Publish directory: `dist`

### Варіант 3: Vercel
```bash
npx vercel
```
Vercel автоматично розпізнає проєкт на базі Vite і виконає збірку.
